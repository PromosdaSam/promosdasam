Política de Privacidade

Última atualização: maio de 2026

O aplicativo Promos da Sam Oficial respeita a privacidade dos seus usuários.

Dados coletados

Este aplicativo não coleta dados pessoais de usuários finais. Ele opera de forma automatizada para publicar conteúdo de curadoria de ofertas no Pinterest.

Uso das informações

As informações de autenticação com a API do Pinterest são utilizadas exclusivamente para publicação de pins de produtos em promoção. Nenhum dado é compartilhado com terceiros.
