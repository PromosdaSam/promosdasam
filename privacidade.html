Política de Privacidade

Promos da Sam Oficial · Última atualização: agosto de 2026

📋 Sobre este documento

Esta política descreve como o site Promos da Sam Oficial (promosdasam.com.br) trata as informações de quem o visita, e como as contas ligadas a ele (Instagram, YouTube) tratam dados no contexto de suas integrações com APIs de terceiros (ex.: Pinterest).

📦 Dados coletados

Este site é uma vitrine estática de produtos em promoção — não tem cadastro, login ou formulário que peça dados pessoais. Nenhuma informação pessoal de visitantes é coletada, armazenada ou processada por nós.

🔗 Links de afiliado

Os produtos exibidos contêm links de afiliado — se você compra através deles, podemos receber uma comissão, sem custo adicional para você. A curadoria e publicação dos produtos é automatizada.

🔐 Uso das informações (integrações de API)

Quando contas ligadas a este projeto se conectam a APIs de redes sociais (ex.: Pinterest), as credenciais de autenticação são usadas exclusivamente para publicar conteúdo de curadoria de ofertas em nome da própria conta. Nenhum dado é compartilhado com terceiros ou usado para fins publicitários.

🌐 Hospedagem e terceiros

Este site é hospedado via GitHub Pages e pode usar um serviço de CDN/DNS de terceiros (ex.: Cloudflare) para entrega de conteúdo. Esses provedores podem coletar dados técnicos básicos de acesso (ex.: endereço IP, tipo de navegador) como parte normal da operação de qualquer site na internet — não temos acesso a esses dados nem os usamos para nenhum fim.

🍪 Cookies

Este site não utiliza cookies próprios de rastreamento ou análise.

👶 Privacidade infantil

Este site não é direcionado a menores de 13 anos e não coleta intencionalmente informações de crianças.

✏️ Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização está sempre indicada no topo desta página.
