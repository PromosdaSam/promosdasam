Política de Privacidade

Promos da Sam Oficial · Última atualização: maio de 2026

📋 Sobre este documento

O aplicativo Promos da Sam Oficial respeita a privacidade dos seus usuários. Esta política descreve como tratamos as informações no contexto da integração com a API do Pinterest.

📦 Dados coletados

Este aplicativo não coleta dados pessoais de usuários finais. Ele opera de forma automatizada para publicar conteúdo de curadoria de ofertas no Pinterest. Nenhuma informação pessoal é armazenada ou processada.

🔐 Uso das informações

As informações de autenticação com a API do Pinterest são utilizadas exclusivamente para publicação de pins de produtos em promoção em nome do próprio canal. Nenhum dado é compartilhado com terceiros ou utilizado para fins publicitários.

🍪 Cookies

Este site não utiliza cookies de rastreamento ou análise. Nenhum dado de navegação é coletado pelos nossos sistemas.
